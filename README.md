# QEMU smoke tests

Small programs and reproduction scripts for QEMU development discussions.

- [RFC VLEN=32 v1](rfc-vlen32-v1/README.md) reproduces a RISC-V GVEC descriptor
  failure with four QEMU builds and 16 configurations.
- [Prebuilt QEMU binaries](qemu-binary-vlen32/README.md) provide the four tested
  x86-64 Linux executables, checksums and source information.

dependencies retain their own copyright and license notices.
